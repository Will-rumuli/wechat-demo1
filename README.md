# 我们群里少了一个人 · 微信小游戏

微信小游戏推理剧本 Demo，支持单机与好友联机。你随机扮演四位邻居之一，在群聊与楼栋地点之间拼出真相。

## 运行

1. 打开微信开发者工具，选择「导入项目」，目录指向本文件夹 `demo1`。
2. `project.config.json` 已填好 AppID（`wxaa3a64e1a197c64d`）；若提示无权限，换成自己的小游戏 AppID 或用测试号。
3. 点击编译即可，游戏为竖屏，无外部素材依赖。
4. 首次启动先登录（微信授权或本机一键登录），登录后才进入黑屏开场。

## 联机配置（微信云开发）

1. 在开发者工具顶部打开「云开发」，开通环境并复制环境 ID。
2. 把环境 ID 填入 `js/config.js` 的 `CLOUD_ENV`；留空则使用当前默认环境。
3. 在云开发控制台新建数据库集合 `rooms`（权限保持默认即可，读写都通过云函数）。
4. 右键 `cloudfunctions/room` 选择「上传并部署：云端安装依赖」。
5. 重新编译。多人游戏会创建 6 位房间号，点击空席位转发给好友或群聊，好友通过分享卡片进入补位。

> 联机需要真实的微信小游戏 AppID 与已开通的云开发环境；未配置时点击「多人游戏」会提示先部署 `room` 云函数。

## 玩法

- 随机获得身份：老周（保安）、林晚（404 住户）、阿凯（外卖员）、陈姐（保洁）。
- 角色页会展示你的秘密、个人目标与 3 张初始线索，点线索可看详情。
- 每一轮选择一个地点调查，找到的线索只进你的手牌。
- 调查后进入讨论：你可以公开 1 条线索，AI 会根据内容辩解、闲聊或指认别人。
- 三幕共 8 轮（3 / 3 / 2），每幕结束触发一个公共事件。
- 最终回答三个问题：苏晴在哪、谁最可能在说谎、你们怎么做。
- 4 个结局：帮她离开 / 报警 / 通知物业 / 隐藏结局。
- 隐藏结局条件：在 B1 找到 C17 或 C18、位置判断正确、并选择「帮她离开」。

### 多人联机

- 剧本详情页选择「多人游戏」，发起人成为房主，席位数量与剧本人数一致。
- 房主点击空位邀请好友；好友通过分享卡片进入并补位，满员后提示房间已满。
- 组员点击「准备 / 已准备」切换状态，房主默认视为已准备；人满且全员准备后房主才能开始。
- 房主退出会解散队伍，组员退出只离开房间；两者都会回到剧本库。
- 对局中所有人看到相同的幕、回合和地点，各自调查一个地点；每回合每名玩家可公开 1 条线索。
- 全员点击「结束本轮」后，服务端统一推进到下一回合；所有幕结束后进入各自投票与结算。

## 美术与音频

- 全部画面由 Canvas 代码生成，没有一张外部图片：夜空渐变、远景楼群、403 红色窗框、雨丝、暗角、噪点、角色剪影、地点图标与封面。
- 音频为本地合成后压成 AAC（m4a，单声道），全程悬疑氛围：低频无人机与环境雨噪打底，每 7.5 秒一次心跳，稀疏的不和谐金属泛音制造不安；点击音是闷响，线索音是小二度紧张音簇，不使用明亮旋律。
- 背景音乐 60 秒无缝循环，首次触摸后解锁；剧本库右上角可静音。
- 存档使用 `wx.setStorageSync`，记录调查次数、已收集结局、单局最多线索；登录资料单独保存在 `wgq_user_v1`。

## 扩展新剧本

剧情与数值全部集中在 `js/data/case1.js`、`js/data/case2.js`：替换 `ROLES`（角色与私密线索）、`CLUES`（线索卡）、`ACTS`（幕与地点池）、`TRUTH`（真相段落）、`ENDINGS`（结局）、`QUESTIONS`（最终三问）即可。详情页简介取 `CASE.synopsis` / `CASE.tags`。新增剧本后，在 `js/data/scripts.js` 注册，并在 `CASE.open` 中开放卡片；联机席位会自动取 `ROLES.length`。

## 当前范围

- 单机版：1 名真人 + 3 名 AI 队友。
- 联机版：微信云开发房间服务，最多与剧本人数相同的真人同局，全员同步推进。
- 已开放两个剧本：《今晚别上四楼》（3 幕 8 轮）与《群里多了一个“人”？》（5 幕 15 轮），重复游玩会触发不同角色与不同线索组合。
